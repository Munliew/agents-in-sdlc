ワークスペースを確認してクイックチャットを試しました。次は**エージェントセッション**を開始し、プロジェクトに最初の変更を加えます。変更は小さくします。ゲームのデータには星評価がありますが、ホームページのゲームカードにはまだ表示されていません。エージェントに表示を依頼し、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次のことを行います。

- エージェントセッションを開始し、その構成を確認します。
- 対象を絞った小さな変更を依頼します。
- ワークスペースの差分ビューで変更をレビューします。
- アプリをローカルで実行し、ブラウザーで変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。しかし、ホームページのゲームカードにはタイトル、カテゴリ、パブリッシャー、説明しか表示されません。最初の練習として、各カードに既存の評価を表示するようエージェントに依頼します。初回セッションにちょうどよい、小規模で独立した変更です。

## セッションの構成

**セッション**は、分離された独自のワークスペースで実行されるエージェントとの会話です。各セッションには**専用の git worktree とブランチ**が割り当てられます。そのため、一方のセッションで機能を追加し、もう一方でバグを修正するなど、変更を競合させずに複数のセッションを実行できます。セッションはサイドバーでリポジトリごとにまとまり、選択して切り替えられます。

セッションには、エージェントとの**会話**、ファイルを調査・編集するエージェントの**ツール操作**、差分付きの**変更ファイル**一覧が表示されます。

## セッションを開始して変更を依頼する

新しいセッションでプロジェクトを調べ、機能を実装します。[アプリのセットアップ][prior-lesson]で GitHub リポジトリからプロジェクトを追加しました。そのリポジトリに新しいセッションを作成し、変更を依頼します。

1. GitHub Copilot app に戻るか、アプリを開きます。
2. サイドバーの上部にある **+** を選択してセッションを開始します。
3. リポジトリとして `tailspin-toys` を選択します。
4. プロンプトボックスの下で **new working tree** と **Interactive** モードを選び、次のプロンプトを送信します。

    ```plaintext
    ゲーム一覧ページの各ゲームカードに、各ゲームの starRating を 5 段階で表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトは維持し、テストを追加して、関連するチェックを実行してください。
    ```

5. <kbd>Enter</kbd> を押してプロンプトを送信します。

Copilot app は最初にプロジェクトの分離されたコピーである新しい worktree を作成します。次にプロジェクトを調べ、機能追加に必要なファイルを探して、コードを作成します。Copilot app を使って新機能を追加できました。

## 差分をレビューする

小さな変更でも、AI が生成したコードはマージする前にレビューします。Copilot app で変更を確認しましょう。

1. アプリの右上にある **Toggle review panel** を選択します。開いたパネルで **Changes** を選び、変更されたファイルと差分を確認します。

    ![Create PR の右側に Toggle review panel ボタンがある GitHub Copilot app の上部ツールバー](../../../_images/app-2-review-panel.png)

2. ゲーム詳細の表示に使う `GameCard.astro` にコードが追加されていることを確認します。評価がある場合は表示し、`starRating` が `null` の場合は "No rating yet" を表示する、次のような小さなブロックが追加されます。

   ```astro
   {game.starRating !== null ? (
       <span class="text-xs font-medium px-2.5 py-0.5 rounded bg-amber-900/60 text-amber-300" data-testid="game-rating">
           ★ {game.starRating} / 5
       </span>
   ) : (
       <span class="text-xs font-medium text-slate-500" data-testid="game-rating-empty">
           No rating yet
       </span>
   )}
   ```

> [!NOTE]
> Copilot を含む生成 AI ツールは確率的に動作するため、コードは例と異なる場合があります。似た実装になるはずですが、完全一致は必要ありません。

## 変更を確認する

ブラウザーを開く前に、エージェントが実行した自動チェックの結果をレビューします。数値の `starRating` と、`null` の場合の代替表示の両方をテストしていることを確認します。前提条件が不足していたり、チェックがスキップされたりしている場合は成功ではありません。インストールの要求は内容を確認してから承認してください。

コードを読むだけで動くと判断するのではなく、Copilot に Web サイトを起動させ、ブラウザーキャンバスで更新された UI を確認します。

> [!TIP]
> キャンバスは、Copilot app 内で利用できるインタラクティブなウィジェットです。後のレッスンでカスタムキャンバスを調べて作成しますが、ここでは組み込みのブラウザーキャンバスを使います。

1. 次のプロンプトを使い、アプリを起動してブラウザーキャンバスで開くよう Copilot に依頼します。

    ```plaintext
    アプリを起動して、ブラウザーキャンバスで開いてください。
    ```

2. しばらくするとアプリが起動し、Copilot app 内にブラウザーウィンドウが開きます。
3. 評価済みのゲームカードに 5 段階の値が表示されることを確認します。
4. 確認が終わったら、次のプロンプトを使い、このセッションで起動した開発サーバーを停止します。

    ```plaintext
    開発サーバーを停止し、ブラウザーキャンバスを閉じてください。
    ```

## 最初のプルリクエストを作成してマージする

機能を作成できました。次に、新しいコードをコードベースに取り込むプルリクエスト (PR) を作成します。

1. 右上隅の **Create PR** を選択します。
2. 認証を求められた場合は、**Sign in with your browser** を選択し、表示される手順に従います。
3. PR を作成する前に、リポジトリのポリシーにより関連 issue が必要だと Copilot が説明した場合は、その手順に従うよう確認します。
4. Copilot が PR を作成します。
5. チャットのすぐ上にある **PR** バブルを選択し、レビューペインで PR を開きます。ここで PR をレビューできます。
6. 準備ができたら **Ready to merge** を選択します。
7. 表示されたダイアログで **Merge pull request** を選択して PR をマージします。

## まとめと次のステップ

GitHub Copilot app を使って、最初の変更をリリースしました。このレッスンでは、次のことを行いました。

- エージェントセッションを開始し、その構成を確認しました。
- エージェントにゲームカードの対象を絞った小さな変更を依頼しました。
- ワークスペースの差分ビューで変更をレビューしました。
- アプリをローカルで実行し、ブラウザーで星評価を確認しました。
- PR 1 を作成し、チェックをレビューして、明示的にマージしました。
